# Newsletters

GTM newsletter activities, tracked per publication and issue.

## The Context Window (DL)

Each issue lives under `the-context-window/issue-NNN/` and starts life as an
approved slot **brief** — the committed angle plus the constraints, audiences,
ethics check, and open prerequisites it must be drafted against. The brief is
the source of truth for the decision; drafts are produced against it.

### Slot proposal workflow

Slot proposals are raised in Slack and resolved with one of:
`approve` / `revise: …` / `reject` / `full: #2`. An `approve` commits the
proposed angle and its brief; the record for that decision is captured in the
issue's `brief.md`.
